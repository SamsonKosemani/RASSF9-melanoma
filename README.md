# RASSF9 melanoma analyses

Analysis code for Kosemani et al., "Ultraviolet stress reveals a
growth-restraining function for RASSF9 in melanoma".

## Data

No raw data are redistributed here. The scripts retrieve them from:

- GEO: GSE112509, GSE98394, GSE72056, GSE68379, GSE298774, GSE230574, GSE151091
- TCGA-SKCM: NCI Genomic Data Commons, via TCGAbiolinks
- DepMap Public 26Q3: depmap.org/portal/download

The GSE298774 per-spot compartment assignments were provided by the
authors of that study and are not redistributed; only aggregated
summaries derived from them appear here.

## Running

R 4.6.1. `R/00_setup.R` defines shared paths, logging and figure
settings and is sourced by every other script. Scripts are numbered in
execution order and are run from the project root.

| Scripts | Analysis |
| --- | --- |
| `00` | Shared setup: paths, palettes, logging |
| `01`-`11` | TCGA-SKCM: UV mutational signatures, expression, methylation, adjusted models, summary tables |
| `12`-`16` | GEO bulk cohorts: nevus versus melanoma, cell lines |
| `17`-`20` | GSE230574 single-cell: depth matching, lineage, stromal adjustment |
| `21`-`33` | GSE298774 spatial: QC, deconvolution, author labels, bulk comparison, figures |
| `34`-`36` | TCGA methylation: broader cohort, full cohort, locus specificity |
| `37`-`38` | Single-cell detection: Belote (GSE151091) and Tirosh (GSE72056) |
| `39`-`41` | Mutational burden, anatomical site adjustment, keratinocyte axis |
| `42`-`49` | Cancer cell lines: DepMap expression, GDSC 450K methylation, pan-cancer analysis |
| `50`-`53` | Manuscript figures |

Each script writes a log to `results/logs/`, which is included here so
the reported numbers can be traced to the run that produced them.

## Outputs

- `results/` - summary tables underlying the reported statistics
- `data/processed/` - intermediate tables small enough to include
- Figures are generated by scripts 50-53

## Session information

R and package versions are recorded in `results/`.
